# Sign-in assets

`google-g.png` is Google's approved current G mark, downloaded unchanged from
https://developers.google.com/static/identity/images/g-logo.png on 27 September 2026.
Use only to identify Google sign-in, following
https://developers.google.com/identity/branding-guidelines.

The GitHub mark in `_account_provider_icon.html` is GitHub's Octicons `mark-github`
(MIT): https://github.com/primer/octicons. It identifies GitHub authentication.

Account-page fonts are the same Golos Text and Unbounded versions used by the
application. Their OFL notices are alongside the fonts in `static/fonts/`.
Google Sans Medium (Latin, Google Fonts v70) is used only for Google's button,
as required by the branding guidelines. Its OFL notice is in the same directory.
